# 国内版上线对照（2026-10-23，依据仓库内文档）

对照范围是国内产品。`main` 比 `fixes/energy-p0-2026-10-15` 多出的两笔提交只改国际版 App 图标、名称和启动保护，没有并入本分支。外部整套文档尚未附上，到齐后要按同一张表补行。

状态含义：已有 = 代码里已经这样做；本轮修复 = 这次改的；人工 = 必须由持有账号或资质的人办理，代码侧只留配置位。

## 产品与计费

| 要求 | 状态 | 说明 |
| --- | --- | --- |
| 五档年付，月付停售，运维版只保留存量 | 已有 | 定价以 `runtime/backend/data/entitlements.json` 与网页 `plans.ts` 为准 |

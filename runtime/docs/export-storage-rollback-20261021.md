# 导出存储失败不扣额度

原顺序为额度事务提交后再写文件，磁盘失败时用户没有文件却已扣额度。当前CSV/JSON导出改为在额度事务内准备文件，正文或元数据写入失败则回滚额度；事务失败时清理生成的随机文件名，只有成功提交才返回绑定账户的下载链接。准备回调仅用于受控本地文件写入，不应放入外部模型或支付调用。

43项测试与类型检查通过。新增两个真实隔离数据库场景分别注入正文、元数据写入失败，检查503、无下载链接、额度不变、目录无新增文件。此前完整下载、跨账户拦截和12并发额度测试保持通过。故障是注入的磁盘异常，不是真实磁盘写满或断电测试。证据evidence/2026-10-21-export-storage。

数据库和文件系统不是分布式原子提交：进程崩溃可能留下不可用的临时文件，仍需清理；响应丢失重试幂等、浏览器PDF/Word生成失败退额尚未完成。此变更不覆盖客户端报告预留流程，没有新增UI截图，不表示全部导出/会员验收完成。

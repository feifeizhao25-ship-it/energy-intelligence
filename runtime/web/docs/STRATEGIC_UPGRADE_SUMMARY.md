#### 4. 资产评级API
**目标**：让银行可以调用你的评级

**API**：`GET /api/v2/asset/[id]/rating`

**返回**：
```json
{
  "investmentGrade": "AA",
  "overallScore": 85.3,
  "dimensions": {...},
  "creditEnhancement": {
    "current": "AA",
    "withInsurance": "AAA"
  }
```

**商业模式**：
- 免费：只返回等级

**新增报告类型**：`BANK_CREDIT_REPORT`

- 契约条款建议

# 浏览器巡检步骤

本文件是操作说明。这次没有接上浏览器性能接口，所以没有填写最大内容绘制、累计布局偏移或控制台错误的实测值。不要把空白当成 0。

每周对生产首页和角色工作台做一次：

1. 打开页面。
2. 记录可见文本和截图，页脚要能读到提交号。
3. 看控制台是否有报错。
4. 在性能面板看最大内容绘制、累计布局偏移和交互响应。目标分别是不超过 2.5 秒、0.1，以及没有控制台报错。
5. 把结果交给企业微信，不在这里填写未测量的数字。

视口：1440×900 与 390×844。语言为中文。

## 2026-10-28 实验室测量

生产模式打开首页 `http://127.0.0.1:3101/`，用 Lighthouse 只测性能。这是这一台机器上的实验室结果，不是线上用户的现场数据。

去掉首屏的两份完整中文字体之后：

- 桌面预设：最大内容绘制从 3.3 秒降到 0.5 秒，累计布局偏移 0.024，性能分从 0.82 到 1。页面体积从约 3426 KiB 降到 352 KiB。
- 手机预设（带默认节流）：最大内容绘制从 19.1 秒降到 3.2 秒，累计布局偏移从 0.07 到 0.069，性能分从 0.74 到 0.92。

桌面已经低于 2.5 秒的目标。手机预设仍高于 2.5 秒，节流下的绘制时间不能当成现场数据。

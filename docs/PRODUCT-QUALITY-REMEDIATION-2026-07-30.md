# 新能源智库产品质量全面修复建议与验收标准

日期：2026-07-30
范围：国内版、国际版、Web、Android、iOS、后端、Skills、RAG、DOCX/PDF

## 核心修改建议

- 项目收益、资源量、政策和标准结论必须展示“数据时间、机构、链接、适用地区、计算假设、置信边界”；模拟数据只能用于明确的演示模式。
- 国内版重点是政策路径、项目备案/并网、中文报告与本地工作流；国际版重点是可融资性、interconnection、税务/市场风险、英文投委会报告，不做菜单翻译。
- 所有计算 Skill 采用“输入→公式→单位→结果→敏感性→限制条件”的展示顺序，并用独立实现或已知案例交叉验证。
- 个性化只改变信息优先级和建议，不改变底层事实；用户可查看原因、修改画像、关闭推荐和删除标签。
- RAG 自动刷新只进入隔离区；版权、robots、哈希、来源差异、评测及人工批准通过后才能发布。

## 验收矩阵

| 能力 | 生产验收 |
|---|---|
| 资源评估 | 真实数据源失败时 fail-closed；不得回退为伪造气象结果 |
| 财务模型 | 公式、单位、币种、税率、基准日、敏感性和免责声明完整 |
| RAG | stale 默认不返回；来源机构/链接/许可/核验日随命中返回 |
| 多方验证 | 只有同语言、同资料类型、不同发布机构的来源才标记 verified |
| 国内/国际 | API、UI、报告分别执行中文/英文隔离测试 |
| Skills | 每个 Skill 有输入边界、黄金样例、反例、数值容差、来源与版本 |
| 会员 | 免费/Pro/企业权益共用单一配置；导出只在任务成功受理后扣额 |
| 个性化 | 五类用户 D1 引导、D2-3 积累、D4-5 洞察、D6 行动、D7 周报 |
| 报告 | DOCX/PDF 逐页渲染检查，表格不跨页错位，来源附录可追溯 |
| 合规 | 中国数据/生成标识义务；GDPR、EU AI Act、消费者保护和绿色声明 |

## 本轮已落地

- 过期资料默认从 RAG 结果中排除，只有显式审计模式可查看。
- 命中结果增加来源链接、发布机构和许可说明。
- “存在 corroborated_by 字段”不再等于已验证；必须满足同语言、同类型、不同机构。
- 新增 stale fail-closed、可点击溯源和严格多方验证回归测试。
- 既有五用户七天个性化引擎、国际仪表盘、会员权益、双语报告和 DOCX/PDF 结构继续纳入发布闸门。

## 必须阻断上线的情况

生产使用 stub/synthetic 数据；过期资料进入默认答案；跨语言内容泄漏；来源不可访问或许可不明；计算无单位/假设；报告未逐页 QA；个性化不可解释或不能关闭；密钥进入仓库。

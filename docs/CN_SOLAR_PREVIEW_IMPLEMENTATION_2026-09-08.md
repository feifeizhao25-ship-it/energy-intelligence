# 国内光伏初步估算实现与验收边界

本记录更新此前 CN_ANALYSIS_TRUTHFULNESS 的临时关闭状态：V2 光伏 POST 和项目分析 POST 已恢复为有证据、保存记录的初步估算。自动监测、完整报告与审计级分析仍未开放。

## 实现

- verified-solar 请求 NASA POWER 上一完整公历年的月度辐照，不再固定 2022 年或使用模拟年值。核验响应年份、坐标、UTC 时间标准、单位、12 个月、缺失标记和有限数值，按每月实际天数（含闰年）累计。保留请求 URL、原始响应、实际覆盖期、获取时间与 SHA-256。失败不回退为旧值。
- project-finance 统一第 0 年初始投资和年末经营现金流，修复重复扣投资以及漏计首年运维费用。NPV、LCOE、IRR 和回收期共用现金流；未回本或无法确认唯一 IRR 使用 null。采用明确的简化假设，拒绝非法输入与数值溢出。
- solar-v2 将容量、辐照与综合效率连接为初步发电量估算；保留假设、输入和证据的完整哈希。用户填写的电价及补贴始终标为用户输入，不冒充政策来源。不生成无依据的置信区间、合规认证或审计等级。
- save-solar 在同一数据库事务内锁定用户、重新核验项目归属和会员有效期、保存快照与项目时间线并计入北京时间当日用量。失败整体回滚；数据库成功提交后才返回 persisted=true。配额采用现有 auth/config 的六种套餐权益，不增加新的收费规则。
- 项目分析复用同一测算与保存路径，以 URL 项目编号覆盖客户端伪造编号。完整报告请求明确拒绝，避免将内容组装误报为可下载文件。

## 验证

本地 Jest 24 个测试集、219 项通过；TypeScript noEmit 通过。手算案例独立验证一年/两年的现金流，另覆盖负 IRR、高于 50% 的 IRR、无根、未回本、溢出、闰年、缺月、单位和坐标错误、过期会员、归属、保存失败与跨入口编号替换。

2026-09-08 用 curl 实际取回北京（39.9,116.4）2025 年数据。Node 25 配置 NODE_USE_ENV_PROXY=1 的适配器调用也曾成功：12 个月、1508.3276 kWh/m²，响应 SHA-256 为 f1d992c2f3d4075f2cdc939d6d19de871dd95394257c9536af6dfdf00d9ad6e1。直接连接及后续代理复测出现失败，网络可达性不稳定，不能记为生产网络验收通过。不得把单年历史水平面辐照称作组件实际发电量或长期气候均值。

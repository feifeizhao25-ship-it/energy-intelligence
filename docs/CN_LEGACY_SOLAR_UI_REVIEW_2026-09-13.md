# 旧光伏页面状态与结果展示纠错

核对现有光伏实现文档与实际路由后，确认 /calculator/solar 仍调用 /api/calculator/solar。该旧接口的会员中间件返回空会话，不能记为已经接通生产测算。本次没有绕过认证。

- 表单尚未提交时改为「尚未保存」，撤下假定配额检查通过的死代码。
- HTTP 失败、未登录、用量限制、响应不完整及网络错误均给出中文提示，不再静默停留。旧入口未接通登录时明确提示其限制。
- 结果页去除固定 +1.2% 收益变化值和 PRO/审计暗示，使用初步估算、计算记录编号。
- URLSearchParams 已经解码查询值，结果 JSON 不再二次 decodeURIComponent，防止项目名含百分号时导致有效结果无法显示。
- 透传接口返回的 metadata，避免页面组装结果时丢掉来源元数据；这并不代表所有来源字段已在 UI 完整呈现。

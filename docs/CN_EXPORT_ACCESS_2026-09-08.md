# 导出文件归属与安全修复

新能源实际导出入口已按用户查询数据，但下载入口没有身份与文件归属验证，且文件名只有时间戳。现在创建文件保存 ownerId，下载要求同一登录用户；无归属的旧文件、过期、损坏或非法路径统一拒绝。元数据通过后才读取内容，响应 private/no-store 和 nosniff。

文件名增加 UUID，磁盘写入使用排他创建避免同名覆盖；内容和元数据权限 0600。有效期在读取时校验，不依赖进程内清理计时器；清理计时器不再阻止进程退出。CSV 用户文本的公式前缀做中和处理，原始数值负数和零保留；JSON 保留原始内容。年发电量 0 不再被判为缺失，文件 size 使用实际 UTF-8 字节数。

验证：网页全部 159 项测试（19 套）及 TypeScript noEmit 通过。新增 18 项覆盖真实磁盘文件读写、路由会话、跨用户拒绝、过期/旧版/损坏元数据、路径穿越、头部注入文件名、同名拒绝、同毫秒两次导出、公式文本、中文 CSV 与零值。数据库、认证会话和额度服务在路由测试中使用明确替身，不能称为真实生产账号全链路验收。

没有修改界面布局，未生成新 UI 截图。多实例对象存储、文件持久化清理任务、完整 PDF/Word 排版以及导出失败额度补偿仍待处理。生产发布和真实付款未完成。

# 错误码对照表

用户看得见的错误文案只从 `runtime/backend/app/errors/catalog.json` 读取。国内版用 `zh`，国际版用 `en`。下面这张表与那份 JSON 必须逐条一致，测试会核对。

| 代码 | 场景 | HTTP | 中文 | English |
| --- | --- | --- | --- | --- |
| E_CONFIG | 缺少配置 | 503 | 这项服务还没有配置好，请稍后再试。 | This service is not configured yet. Please try again later. |
| E_AUTH | 未登录 | 401 | 请先登录后再继续。 | Please sign in to continue. |
| E_FORBIDDEN | 无权限 | 403 | 当前账号没有这项权限。 | This account does not have permission to do that. |
| E_QUOTA | 额度用尽 | 429 | 当前周期的额度已经用完。 | The quota for this period is used up. |
| E_COMPLIANCE | 合规拦截 | 403 | 这条内容没有通过合规检查。 | This content was blocked by the compliance check. |
| E_SERVICE | 服务失败 | 503 | 服务暂时不可用，请稍后再试。 | The service is temporarily unavailable. Please try again later. |
| E1001 | 请求参数无效 | 422 | 请求参数无效 | Invalid request parameters. |
| E1002 | 缺少必需参数 | 422 | 缺少必需的请求参数 | A required parameter is missing. |
| E2003 | 认证失败 | 401 | 认证失败或令牌无效 | Authentication failed or the token is invalid. |
| E2004 | 邮箱或密码错误 | 401 | 邮箱或密码错误 | The email or password is incorrect. |
| E2005 | 验证码无效 | 400 | 验证码无效或已过期 | The verification code is invalid or has expired. |
| E2007 | 刷新令牌过期 | 401 | 刷新令牌已过期 | The refresh token has expired. |
| E2008 | 令牌类型不匹配 | 401 | 令牌类型不匹配 | The token type does not match. |
| E4001 | 用户不存在 | 404 | 用户不存在 | User not found. |
| E4003 | 邮箱已注册 | 409 | 该邮箱已被注册 | This email is already registered. |
| E5001 | 服务器内部错误 | 500 | 服务器内部错误 | The service is temporarily unavailable. Please try again later. |

开关：无开关。这张表默认生效。

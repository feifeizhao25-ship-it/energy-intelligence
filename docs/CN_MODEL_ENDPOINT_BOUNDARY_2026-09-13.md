# 国内网页模型调用边界修复

检查发现 runtime/web/src/lib/ai/qianwen.ts 原先直接采用 SILICONFLOW_BASE_URL 任意覆盖值，并默认跟随 HTTP 重定向。该调用携带用户消息与 API key，不能仅凭「国内版」标签证明目标受约束。

现在仅允许 https://api.siliconflow.cn/v1（可带尾斜杠），拒绝其他域名、协议、非默认端口、URL 用户凭据、查询串、片段和其他路径，错误不回显配置值。非流式、初始流式、工具执行后的第二次请求均设置 redirect=error。未配置仍使用既定国内端点，不增加海外兜底。

删除上游 HTTP 错误响应体在日志和异常中的原样输出，仅保留中文错误与状态码。工具后续请求返回失败或没有响应流时抛错，不再继续输出 done，避免部分工具结果被包装为回答完成。

验证：Jest 31 套 267 项、TypeScript noEmit、Next.js webpack 生产构建通过。新增 17 项测试覆盖端点白名单、敏感配置不回显、非流式/流式错误、请求前阻断及工具续答失败不输出完成事件。网络使用替身，无真实模型调用、真实费用或服务连通性验收。

边界：本轮只覆盖 qianwen.ts 调用链。Python 后端各模型 BASE_URL、其他 SDK 调用、工具参数异常日志、流式截断与完成原因验证、模型别名/会员权益一致性、真实供应商数据保留策略还需继续审查。端点白名单不等于所有数据已满足境内存储要求，也不代表模型输出准确性得到保证。

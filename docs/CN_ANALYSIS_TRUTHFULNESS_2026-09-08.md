# 国内 V2 分析接口真实性与权限修复

日期：2026-09-08。

## 发现

SolarCalculatorV2.fetchSolarResource 未请求外部数据，固定返回 annualGHI=1456.7，却标记来源 NASA POWER 和当前时间。项目分析调用的评分服务使用模拟项目；时间线管理器的写入与查询均未实现。原接口还缺少项目归属检查，旧光伏接口允许把快照关联到任意项目，并在保存失败后仍以登录状态推断 persisted=true。

## 本轮处理

- 项目分析 POST/GET 均先校验登录与项目归属，未知和他人项目统一 404。
- GET 接入真实 ProjectTimeline 表，同时限定 projectId、userId，稳定排序并最多返回 20 条。无依据的统计和当前评分返回 null，明确历史记录不代表已经通过来源或审计核验；数据库故障返回 503，不伪装为空历史。
- 项目深度分析 POST 暂停返回结论，明确返回中文不可用信息。V2 光伏 POST 同样返回不可用，绑定项目时先检查归属，不再生成虚假来源、置信度、审计承诺、快照或事件。
- 计算器底层也移除固定模拟来源，直接调用时失败关闭，避免后续接口重新暴露虚假证据。
- 禁止缓存用户数据，错误响应不暴露数据库细节。国内 runtime/web 搜索未发现这两个 V2 接口的直接页面调用；这不替代浏览器验收。

## 验证

本地全部 21 个 Jest 测试集、190 项通过；TypeScript noEmit 通过。新增 12 项覆盖匿名与跨用户访问、历史数据库读取契约、数据库失败、异常参数及直接计算器调用。数据库和身份使用测试替身，不能宣称已做生产集成验收。

# 国内计算记录访问与回看修复

旧 /api/audit/[id] 原本允许匿名凭编号读取完整记录，含输入、输出、IP 和客户端字段。本轮要求真实登录并核验记录归属；不存在与其他用户记录统一返回 404。响应移除 IP、客户端标识、用户及组织编号，成功与错误均使用 private, no-store。V2 快照接口保留数据库归属筛选，补上中文错误和私有禁止缓存响应。

旧完整性校验在 checksum 缺失时返回 valid=true；现改为明确无法验证。存在但不匹配也继续拒绝。校验值一致仅用于发现内容变化，不代表来源正确、合规认证或密码学签名。

/audit/[snapshotId] 改为真实会话下直接查询本人 calculationSnapshot，不再依赖请求 Host 拼接 URL 后匿名读取旧 auditLog 接口。新光伏成功结果提供对应记录链接。页面显示存储时的结果，null 收益率与未回本不伪造数值，数据库故障与记录不存在分开呈现。

/audit 列表按当前用户读取最近 50 条，保留稳定排序。数据库失败不再吞掉后显示空列表。移除无实际处理器的搜索、筛选、下载和监控按钮；撤下金融评审、不可篡改加密快照等未经验证的承诺。用可换行卡片替代固定六列表格。超过 50 条的分页和其他计算类型专用详情仍待实现。

验证：Jest 29 套 250 项通过（新增 13 项），TypeScript noEmit 与 Next.js webpack 生产构建通过。回归覆盖匿名拒绝、跨用户拒绝、不泄露客户端字段、私有缓存、缺少校验值、数据库失败、保存结果的空收益指标和列表空状态。本轮页面测试使用服务端渲染与 Prisma 替身，没有生产登录、真实多用户数据库或登录后浏览器截图验收；不能据此宣布这些外部链路通过。

上一轮 2938076 的 Full Test Suite 和 Security Gate 已成功。Deploy to Production 失败于 AWS_ACCESS_KEY_ID 缺失；国内版目标为阿里云，不能为了让旧 AWS 工作流通过而将其视作国内部署。阿里云迁移/部署脚本和真实目标环境仍需继续核验。

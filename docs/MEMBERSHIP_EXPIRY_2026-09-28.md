# 国内支付宝会员到期与续费修复

后端 User 新增 subscription_expires_at，迁移为 0005_subscription_expiry。已验证支付宝支付按订单月付/年付计算日历到期日，月底与闰年夹取有效日；同套餐未到期续费从原到期日追加，重复回调不重复追加。付款事务锁定用户行，避免不同订单并发续费丢失时长。关闭、退款中或已退款订单不能重新开通。

User.plan 在到期后返回 free；额度、权益、用量与个人资料消费该有效套餐。原始 subscription_plan 保留用于审计。没有历史到期日的旧记录不擅自过期，需对账补齐，不宣称历史会员都已自动修正。

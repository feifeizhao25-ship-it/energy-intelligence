# 文献数据源修复记录（2026-09-06）

本次修复国内 runtime/web 的 OpenAlex PDF 字段、可选服务端 API 密钥、10 秒请求超时、损坏响应识别，以及多源合并修改缓存数组的问题。

依据：
- https://help.openalex.org/api/authentication/ （页面更新 2026-08-19）：支持 Authorization Bearer，匿名基本查询仍可用。因此不将旧公告中的“必须有密钥”当作当前事实，也不再因缺少联系邮箱阻止生产请求。
- https://help.openalex.org/data/locations/ （页面更新 2026-08-17）：PDF 位于 best_oa_location.pdf_url，且需确认该位置 is_oa。

验证：2 个测试套件共 5 项通过；TypeScript 无错误。数据源响应使用契约样例，尚未验收生产密钥和真实在线查询。

未完成：跨源年份与开放获取筛选一致性、分页与去重总数、arXiv XML 解析、未知年份/引用数表示、国内输出语言隔离及真实用户页面。以上不得视为已修复。

## 第二轮：缺失数据与筛选

- Paper 年份与引用数支持 null，三个检索来源保留缺失状态；arXiv 不再补当前年份或零引用。
- 详情、列表、收藏页显示中文缺失提示，收藏不将未知引用数保存为零。
- 按 arXiv 官方手册 https://info.arxiv.org/help/api/user-manual.html 的 link/type 格式识别 PDF，不要求文件扩展名；补充请求超时。
- 合并后统一检查年份与开放全文条件，防止其他来源绕过筛选。
- 全部 18 个 Jest 套件、140 项测试通过；TypeScript 检查通过。

范围限制：这轮筛选属于结果端防护；各提供方原生筛选、跨源分页和总数口径仍需后续修复，当前筛选可能返回不足一页。完整 XML 解析、生产在线契约测试、真实 UI 截图仍未完成。不能以单元测试替代这些验收。

## 第三轮：结果窗口、页面和国内路由

各来源最多检索 100 条候选记录，API 在合并后应用 offset，total 仅指该候选窗口内筛选去重的数量，并返回 totalScope=retrieved_window。当前页面一次获取最多 100 条，每次展示 10 条，查看更多直接使用本次结果，避免重复请求引起结果变化；不代表整个数据库论文数量。原生来源筛选和更深检索仍未完成。

页面新增检索失败、空结果、部分来源不可用提示，高级筛选按钮接通年份和全文条件。浏览器验证发现已登录 /papers 被语言中间件重写为不存在的 /zh/papers，已限制重写仅用于三个仍位于语言目录的旧页面。国内 i18n 固定中文，不读取可被修改为英文的 Cookie。根 404 移除嵌套 html/body。导航图标改为本地 SVG，避免字体未加载时出现 bolt/menu 等英文。

验收：18 套件 141 测试通过，TypeScript 通过；真实 Chrome 在 390×844 下验证 10→12 条分页、503 后清除旧结果，无横向溢出、无页面脚本异常。截图已查看并调整标题换行。可重复脚本：runtime/web/scripts/verify-papers-ui.cjs。浏览器使用本地测试身份和契约样例，不能计作生产登录、在线学术接口或真实付款验收。

# 国内版页面密度

新页面使用 `PageShell`：顶部一句事实和三个关键数，主栏与辅栏约 62/38，底部合规条。首屏模块由首页规则表限制为最多 8 个。

颜色、圆角和阴影优先用 `globals.css` 里的变量（`--moss`、`--ink`、`--line`、`--warn`、`--danger`）。按钮可以用强调绿，小字不用。

仍有一批旧页面直接写了色值。这次没有把全部旧页面改完，所以还不能说全站硬编码颜色已经降到 20 处以内。新写的预览、时效看板、术语和阅读模式不再新增色值。

字体使用仓内的思源黑体简体子集（Noto Sans SC，400 与 700）。鸿蒙字体在法务确认前不接入。

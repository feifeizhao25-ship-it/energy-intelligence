# 国内优惠码与自动监测接口复核

日期：2026-09-08。

## 已修复

- 优惠码验证移除写死的示例优惠、使用人数与有效期，改为读取 DiscountCode 表；要求登录并校验输入、付费会员计划、停用状态、生效时间、到期时间、次数上限（包括零次）与折扣范围。
- 优惠码响应明确为资格预览，不预扣次数。数据库失败返回不可用，不能降级为示例数据。
- 项目监测的 POST、GET、PUT 使用登录用户与项目 ID 联合查询归属；匿名返回 401，未知或他人项目返回相同的 404。
- 删除未持久化、未接入采集和调度却返回激活/暂停成功的接口逻辑。当前对本人项目返回 503 和中文未开通提示，无虚构监测状态，也不诱导用户付费升级以开启尚未提供的功能。
- 响应禁止共享缓存，不将底层异常返回用户。

## 验证

本地 Jest 全量 20 个测试集、178 项通过；TypeScript noEmit 通过。新增 19 项覆盖身份、归属、真实数据库查询契约、无效/停用/过期/未生效/耗尽优惠、非法参数和服务异常。这些是代码回归，使用模拟身份与数据库，不代表生产优惠已配置或监测已实际运行。

## 未完成与验收边界

- 优惠结算仍需在创建付款订单时重新核验，保存服务端价格快照，并原子核销或预留优惠次数；预览接口不能作为付款金额依据。本轮没有创建或启用营销优惠码。
- 监测服务仍需实现持久化状态、采集适配器、任务调度、失败重试、停止任务和状态查询。外部还需设备接口权限、真实设备数据和部署环境。返回不可用是防止虚假承诺的临时措施，不是自动监测功能完成。
- V2 项目分析接口及底层时间线/报告的真实性、项目权限与会员权益仍需进一步核查。
- 未开展本轮真实付款、生产部署或 UI 截图验收，不能据此认定四项目已经全部具备上线条件。

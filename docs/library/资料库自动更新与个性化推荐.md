# 新能源智库·资料库：自动更新与「为你推荐」

本文是 `待审核资料库说明.md` 的补充，说明资料库怎么保持更新、怎么按用户个性化推荐，以及哪些事必须由人来做。

## 原则

- **不审核不上线。** 所有条目默认「待审核」。只有 `POLICY_REVIEWERS` 名单里的审核人用审核命令（或同等的人工流程）通过之后，条目才会出现在应用里。名单现在是空的，这是有意的：名单由负责人自己填，代码和自动化不得代填。名单为空时无人能审核，所以现在没有任何条目会上线。
- **定时任务只读不改。** 自动任务只抓取、比对、写状态文件和候选清单，从不通过、更新或废止任何条目。
- **用户看不到过时或已废止的内容当作现行内容。** 来源变了、被废止、连续三次抓不到、超过复核期限的条目，会立刻从「为你推荐」和工作台卡片里撤下；列表里仍可打开，但带明确的横幅。
- **只在应用内推送。** 没有短信、邮件、系统通知。

## 自动更新任务

| 任务 | 时间（Asia/Shanghai） | 复用的 SIL 槽 | 做什么 |
| --- | --- | --- | --- |
| `energy.domestic.library_check` | 每天 02:00 | `daily_scan` | 重新抓取每条已登记来源，比对正文摘要；识别「内容变化 / 疑似修订 / 疑似废止 / 新版本 / 链接失效」，写状态（待复核、已更新、已废止）|
| `energy.domestic.library_discover` | 每周日 03:00 | `weekly_cycle` | 读权威来源的列表页，把关键词命中的新文件标题和链接暂存为「待核实 + 待审核」候选，注明「仅读到列表页标题与日期，正文未读」|

- 开关：`LIBRARY_FRESHNESS_ENABLED=1` 才注册定时任务（默认 0，与 `SIL_ENABLED` 互相独立，`SIL_ENABLED` 保持关闭）。
- 白名单：抓取沿用 SIL 的白名单策略；SIL 白名单本身没有改动。`npc.gov.cn` 只有 http，登记为「人工核对」来源，由 TTL 提醒复核。
- 输出：`ENERGY_LIBRARY_DIR`（默认 `var/library`）下的 `library_state_<cn|global>.json`、`library_candidates_*.jsonl`、`library_report_*.md` 和快照；需要人看的变化追加到 SIL 的 `worklist.jsonl`。

## 人工审核

```
python -m app.library.review_cli --edition cn approve en-lib-001 --reviewer <userid>
python -m app.library.review_cli --edition cn update  en-lib-007 --reviewer <userid> --note "更新了什么"
python -m app.library.review_cli --edition global confirm en-intl-002 --reviewer <userid>
python -m app.library.review_cli --edition global repeal  en-intl-004 --reviewer <userid> --note "withdrawn by the publisher"
```

通过后条目带「核对于」日期；更新后带「更新于」日期和用户可见的更新说明（30 天内显示；国内版写中文，国际版写英文）；每次操作写审计日志。

## 个性化「为你推荐」

接口（均需登录，国内版/国际版按 `User.market` 区分，文案和条目互不混用）：

- `GET /api/v1/library/entries` 条目列表（带展示结论和横幅）、`GET /api/v1/library/entries/{id}` 详情
- `GET /api/v1/library/feed` 个性化推荐：每条带「为什么推荐」和「新 / 已更新」标记（相对上次来访）
- `GET|PUT /api/v1/library/preferences` 总开关、关注 / 取消关注 / 不再推荐某个主题
- `POST /api/v1/library/visit`、`POST /api/v1/library/opened/{id}` 记来访和已读

信号：角色、关注的技术、目标、项目（技术和进度）、地区（仅国际版里按国家范围的条目；国内版条目都是全国性文件，不按省份推荐）、关注的主题、读过的内容。偏好存在用户自己的 `usage_quota` 里，随隐私导出和删除一起处理。

首页：和 `/api/v1/home/workbench`（个性化工作台）接在一起——有「新增 / 已更新」或匹配度很高的条目时，工作台多出一张「资料库」卡，点进 `/library`；没有就不出现，不打扰。关闭工作台个性化，或关闭资料库推荐，这张卡就不出现。

## 国内版 / 国际版语言隔离

- 共用的 `reference_library_page.dart`、`library_live.dart`、`personal_home_section.dart` 不含任何面向用户的文字，也没有「中文工厂」。
- 国内版 App 只带 `library_strings_zh.dart`、`personal_home_strings_zh.dart`；国际版 App 只带 `library_strings_en.dart`、`personal_home_strings_en.dart`。
- `scripts/verify_language_isolation.py`（国际版里没有中文）和 `scripts/verify_zh_ui_dart.py`（国内版全中文）都通过，不依赖白名单。

## 需要人做的事

1. 负责人填写 `POLICY_REVIEWERS`，审核人逐条核对原文后通过。
2. 想让自动任务跑起来时，有意识地设置 `LIBRARY_FRESHNESS_ENABLED=1`。
3. `npc.gov.cn` 等「人工核对」来源按复核期限人工复核；候选条目的正文没有被读过，必须人工读原文再决定。

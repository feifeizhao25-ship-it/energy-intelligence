# 新能源智库·政策与数据资料库（待审核）

本目录说明新增的“政策与数据资料库”：条目、来源、审核流程和怎么在预览里看到它。

## 现状

- 共 19 条，**全部是“待审核”**。每条都只收 A 级来源：作者读过官方原文全文（或明确写出读到的范围），并写明出处、文号、发布/生效日期、读取日期和状态（现行 / 征求意见稿 / 已废止 / 待核实）。
- **默认不会显示任何条目**：页面显示“资料正在审核中”，入口也会隐藏。审核通过前，这些条目不会出现在正式界面，也不会被 AI 检索或引用。
- 预览（仅开发和审核用）：国内版 `flutter run --dart-define=SHOW_PENDING_LIBRARY=true`；国际版同一个开关。

## 文件

- `lib/screens/library/reference_library_page.dart`：列表、搜索、分类和状态筛选、详情页、审核门禁（四个 App 共用同一份）
- `lib/screens/library/energy_library.dart`：各版本的文字和设置页入口
- 国际版另有 `library_strings_en.dart`，英文只放在国际版里，国内版没有英文界面
- `assets/library/energy_library_v1.json`（国内版，19 条）；`assets/library/energy_library_intl_v1.json`（国际版，8 条英文）
- 入口：设置页的“政策与数据资料库”/ “Reference Library”，路由 `/library`

## 审核流程

新能源智库的资料先由人工逐条对照原文审核；通过后把 `review_status`（国际版是 `Pending review`）改成已审核。这些条目**不进入** `rag_sources.json`，不影响现有 RAG；是否进入检索由审核通过后另行决定。

国内版 19 条里，12 条是《能源法》和国家能源局的最新统计，7 条是《可再生能源法》（2009 年修正）和《电力法》（2018 年修正）。

《可再生能源法》已列入全国人大常委会 2026 年度立法工作计划（修改，初次审议项目），目前未见修订草案公布；修订后需要更新这几条。

国际版 8 条来自 EIA（公有领域）、IEA 和 Ember（CC BY 4.0，需署名）、英国能源安全和净零部（OGL v3.0）。

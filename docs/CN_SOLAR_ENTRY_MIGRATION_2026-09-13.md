# 国内光伏入口迁移与真实页面检查

## 修复范围

/calculator/solar 已从旧的空会话会员接口迁移到 /api/v2/solar/calculate。/quick-calc/solar 统一重定向到同一表单，避免快速问答默认北京坐标、电价和不完整答案生成结果。服务端继续使用真实会话、归属检查、事务保存与会员用量；没有增加认证绕过。

表单只收取实际受支持的位置、容量、单位投资与电价，不再展示模型没有使用的贷款、角度等选项。单位投资按元/千瓦输入，调用 V2 前除以 1000 转为元/瓦。示例不自动赋值，允许合法的零坐标和零电价。

客户端只有收到 HTTP 成功、persisted=true、PREVIEW、快照编号和完整结果/来源/假设才显示保存成功。回收期、内部收益率的 null 分别显示未回本和无法确认唯一值。结果保留在当前页面，不放入 URL；结果来源周期按 UTC 显示，避免年末 UTC 时间换算成北京时间后误显示下一年。

实际浏览器发现并修复了 hydration 前原生表单提交的问题：按钮初始禁用，脚本就绪后才可提交。请求中禁用控件并用同步引用防重复提交。网络中断不自动重试，提示先核查记录，避免重复计次；这不等于服务器已有请求幂等机制。

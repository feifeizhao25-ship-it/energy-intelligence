# SolarWind Pro 开发总结报告

## 📋 项目概述

**SolarWind Pro** 是一个面向中国新能源从业者的"新能源项目智能决策系统（Energy Decision System）"，用于在项目立项前30分钟内，给出是否值得投资的工程级结论。

## 📊 核心算法实现

### 光伏计算算法
- **资源评估**：基于NASA数据的太阳辐射分析
- **发电量计算**：考虑倾斜角度、方位角、系统损耗
- **经济分析**：IRR、NPV、回收期、LCOE完整计算
- **风险评估**：地理位置、技术参数、投资成本分析

### 风电计算算法
- **风资源评估**：基于NASA和Open-Meteo的风速数据
- **功率曲线建模**：威布尔分布 + 风机特性曲线
- **容量因子计算**：考虑轮毂高度、风速分布
- **技术优化**：风机选型、布置优化建议
